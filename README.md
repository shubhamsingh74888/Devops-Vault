# DevOps Vault (demo)

A practice knowledge vault for DevOps notes, built to learn how to own and maintain a shared Obsidian vault on GitHub.

## Layout

| Folder | Purpose |
|---|---|
| 10-Cloud | Cloud providers, pricing, comparisons |
| 20-Kubernetes | Kubernetes notes and runbooks |
| 30-CI-CD | Pipelines and automation |
| 90-Archive | Old material, not for current use |
| 95-Assets | Images and attachments |
| templates | Note templates |

See CONTRIBUTING.md before adding or changing notes.
